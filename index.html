이 프로그램에 사용된 수학

raylib C++ 코드의 계산 과정을 JavaScript로 옮겼으며, 기본 경사하강법만 사용합니다.

01 / FORWARD KINEMATICS

순기구학

x = Σ cos(θ₁ + ⋯ + θₖ)
y = Σ sin(θ₁ + ⋯ + θₖ)

각 막대의 회전 방향에 따라 수평·수직 성분을 합쳐 끝점 좌표를 계산합니다.

02 / ERROR FUNCTION

오차 함수

E = (x − a)² + (y − b)²

목표점 (a, b)과 끝점 (x, y)의 거리 제곱을 최소화합니다.

03 / GRADIENT DESCENT

경사하강법

Dᵢ = dE / dθᵢ
θᵢ(new) = θᵢ − αDᵢ

합성함수 미분으로 구한 관절별 변화율을 이용해 모든 관절 각도를 동시에 갱신합니다.

※ 모든 각도는 라디안으로 계산합니다. 적응형 학습률, 정지점 탈출, 관절 회전량 패널티 등 추가 보정 알고리즘은 사용하지 않습니다. 학습률이 크면 오차가 증가할 수 있으며, 미분값이 0인 자세에서 멈출 수 있습니다.
